Дисципліна: Основи веб-програмування
Варіант 12: Система безперебійного живлення (ДБЖ)

Мета
Набути практичних навичок зі створення динамічних веб-сторінок з використанням JavaScript для відображення та оновлення даних моніторингу енергетичних об'єктів у режимі реального часу.

Опис
Веб-сторінка для моніторингу системи безперебійного живлення (ДБЖ). Параметри оновлюються вручну (кнопка) або автоматично (таймер кожні 3 секунди). Кожен параметр має кольорову індикацію стану.

Індикація стану

🟢 Норма — значення у нормальному діапазоні
🟡 Попередження — поза нормою, але в межах роботи
🔴 Критично — за допустимими межами (мигання)

Режими роботи ДБЖ

 МЕРЕЖА — живлення від мережі
 БАТАРЕЯ — живлення від акумулятора
 BYPASS — прямий bypass режим


Структура проєкту
/
└── index.html   ← HTML + CSS + JavaScript (єдиний файл)
CSS та JavaScript вбудовані в index.html відповідно у тегах <style> та <script>.

Технології

HTML5 (семантична розмітка: header, main, section)
CSS3 (Grid, Flexbox, змінні, анімації, медіа-запити)
JavaScript (DOM, Events, setInterval, Math.random)


Функціонал

Ручне оновлення — кнопка «Оновити» генерує нові псевдовипадкові значення
Автооновлення — кнопка «Автооновлення» запускає таймер (інтервал 3 сек), повторне натискання зупиняє
Прогрес-бари — наочно відображають значення у діапазоні, колір відповідає стану
Адаптивний дизайн — коректно відображається на мобільних (375 px), планшетах (768 px) та ПК
